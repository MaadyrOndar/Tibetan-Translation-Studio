# Tibetan Studio (Botok + Flask)

Локальное приложение для морфологической сегментации и перевода тибетских текстов с мгновенным поиском по подключённым словарям. Работает на базе тибетского токенизатора **Botok** и веб-интерфейса на **Flask**.

## Основные возможности

* **Умная сегментация тибетского текста:** автоматическое разбиение сплошного текста на слова и частицы с помощью библиотеки `botok`.
* **Мультиформатная база словарей:** одновременный поиск по словарям форматов **ABBYY Lingvo DSL** (`.dsl`) и **StarDict** (`.dict`, `.idx`, `.ifo`), включая *Rangjung Yeshe*, *Tsig Mdzod Chen Mo* и пользовательские глоссарии.
* **Автономная работа на Windows:** проект скомпилирован в готовый исполняемый файл `TibetanStudio.exe` — не требует установки Python и настройки окружения.

## Структура проекта

```text
TibetanStudio/
├── app.py                # Серверная логика на Flask, интеграция с Botok и парсеры словарей
├── TibetanStudio.spec    # Конфигурация сборки PyInstaller
├── requirements.txt      # Зависимости Python (flask, botok)
├── Templates/
│   └── index.html        # Веб-интерфейс студии
└── Dicts/                # Папка для словарей (.dsl и StarDict)
```

## Запуск готовой версии (Windows)

1. Перейдите в раздел **[Releases](../../releases)** справа на странице репозитория и скачайте архив `TibetanStudio_Win64.zip`.
2. Распакуйте архив в любую удобную папку.
3. Запустите `TibetanStudio.exe` (рядом с ним обязательно должны находиться папки `Dicts`, `Templates` и `_internal`).
4. Откройте в браузере адрес, который появится в окне консоли (обычно `http://127.0.0.1:5000`).

## Запуск из исходного кода (для разработчиков)

1. Установите Python 3.10+ и необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
2. Поместите ваши словари (`.dsl` или `.dict/.idx/.ifo`) в папку `Dicts/`.
3. Запустите сервер:
   ```bash
   python app.py
   ```
